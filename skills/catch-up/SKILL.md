# Catch up

The thread is already in context — this skill is the shape of the recap, not retrieval. Answer in the chat, compactly enough to read in under a minute.

## The recap

1. **One line**: what this conversation is working on.
2. **Where it stands**: what is done, verified or decided — a few bullets, oldest first. Skip dead ends that went nowhere unless they closed an option the person might reopen.
3. **What is open**: unanswered questions, half-finished work, anything waiting on the person.
4. **The next step**: the single most useful thing to say or do next, so the person can pick up without re-reading the thread.

## Keep it honest

- Recap only what the thread actually contains. If something promised a result that never arrived — a search that was never run, a file never written — it is open, not done.
- Point at the specific artifact, file or message that carries each outcome, so the person can jump to it rather than take your word.
- If the person has been away long enough for the world to have moved — a dated release, a "latest" fact — flag what may be stale instead of restating it as current.
